## Failure-mode note (not a test in repo, dev-time self-check)

The zero-innerHTML gate was exercised during development: the section's banner
comment contains the literal word "innerHTML" (it documents the rule), which
initially forced the test slice to start AFTER the comment block
(`_history_code_slice` in test_admin_history_ui.py). Simulating an innerHTML
assignment inside renderHistory would fail
`test_history_section_zero_innerhtml` — verified by reasoning against the
regex `re.search(r"innerHTML", slice)`; the slice asserts "historyList" is
present first so an anchor-drift bug cannot silently pass the gate.
